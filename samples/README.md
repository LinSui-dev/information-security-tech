# 共用 BMP 样例

`lsb-demo-256x256.bmp` 是由标准库生成的彩色渐变及中心色块测试图，不含已嵌入的消息，也不含个人图片内容。

- 256×256，未压缩 24 位真彩 BMP，40 字节 BITMAPINFOHEADER。
- 宽度是 4 的倍数，符合课程和当前程序的支持范围。
- 基础顺序 LSB v1 最大可嵌入正文为 24563 个 UTF-8 字节。
- 已用真实 BMP 模块读取，并通过内存嵌入/提取验证；仓库保存的是未嵌入的原图。

在界面中选择此文件作为原图，嵌入后另存到 output/。噪声和带密钥模块均可使用；带密钥模式容量以对应算法计算结果为准。需要验证灰度图支持时，仍须使用 tests/bmp_factory.py 提供的灰度夹具。
